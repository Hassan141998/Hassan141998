### 🎵 Chinook Digital Music Store — SQL Data Analysis

[![Live Demo](https://img.shields.io/badge/🚀%20Live%20Demo-hassan--chinook.streamlit.app-FF4B4B?style=for-the-badge&logo=streamlit)](https://hassan-chinook.streamlit.app/)
[![GitHub Repo](https://img.shields.io/badge/📂%20GitHub-View%20Repository-181717?style=for-the-badge&logo=github)](https://github.com/Hassan141998/SQL-Music-Store)

</div>

A **production-grade** end-to-end data analysis project on the Chinook music store database — featuring advanced SQL, RFM customer segmentation, cohort retention, market basket analysis, and a fully interactive dark-themed Streamlit dashboard.

| Module | Description | Key Output |
|---|---|---|
| 🎤 **Artist Analysis** | Revenue ranking, catalog efficiency | Iron Maiden #1 at $138.60 |
| 📈 **Revenue Trends** | YoY growth with `LAG()` window fn | +7.1% peak growth in 2022 |
| 🎸 **Genre Analysis** | Market share, opportunity gap | Rock 35.5% · Classical 8× upsell ratio |
| 🧠 **RFM Scoring** | 6-segment customer scoring (1–5) | 21 Hibernating = 35% of revenue |
| 🔁 **Cohort Retention** | 19 cohorts × 37 month heatmap | SQLite-compatible CTE approach |
| 🛒 **Market Basket** | Co-purchase pairs via SQL self-join | Alt & Punk + Rock: 54 co-buys |
| 💡 **Business Ops** | CLV, churn detection, employee perf | 13 churned customers identified |

**Tech Stack:**
`Python` `SQLite` `SQL` `pandas` `matplotlib` `seaborn` `Streamlit` `Logging` `Modular Architecture`

**SQL concepts used:** Window functions · CTEs · Self-joins · Multi-table JOINs (6 tables) · `ROW_NUMBER()` · `LAG()` · `PARTITION BY` · `NULLIF` / `COALESCE`
