### 🧠 SegmentIQ — Customer Intelligence Platform

> End-to-end K-Means++ customer segmentation system for financial product recommendation, with a real-time Flask dashboard, Neon PostgreSQL persistence, and one-click Vercel deployment.

[![Live Demo](https://img.shields.io/badge/▲%20Live%20Demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://segment-iq-customer-segmentation-in.vercel.app)
[![Repo](https://img.shields.io/badge/GitHub-View%20Code-181717?style=flat-square&logo=github)](https://github.com/Hassan141998/SegmentIQ-Customer-Segmentation-Intelligence-Platform)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask)
![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)
![Neon](https://img.shields.io/badge/Neon%20DB-00E599?style=flat-square&logo=postgresql&logoColor=white)
![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel)

**What it does:**
- Clusters 1,000 financial customers into behavioral segments using **K-Means++** with automatic optimal-K detection (composite scoring: Silhouette + Calinski-Harabász + Davies-Bouldin)
- Generates personalised **financial product recommendations** per segment in real time via REST API
- Full 7-section interactive dark dashboard: **2D/3D scatter plots**, radar profiles, feature importance, elbow curve, paginated customer table, prediction history
- **14 REST API endpoints** — predictions and model runs persisted in **Neon PostgreSQL**
- Vercel-optimised: model pre-trained at **build time** → 248KB JSON served at runtime (zero cold start latency)

**Model Results:** Silhouette `0.556` · Davies-Bouldin `0.702` · Calinski-Harabász `1048` · PCA variance `74%`

**Stack:** Python · Flask · scikit-learn · Pandas · NumPy · Plotly.js · Neon PostgreSQL · Vercel

### 🤖 AI Resume Analyzer — Smart CV Screening System

> A full-stack AI-powered resume analysis web app that scores CVs against job descriptions using TF-IDF NLP, detects ATS compatibility issues, and generates personalised improvement recommendations.

[![Live Demo](https://img.shields.io/badge/▲%20Live%20Demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://ai-resume-analyzer-5p4l-mfmxlvq2t.vercel.app/)
[![Repo](https://img.shields.io/badge/GitHub-View%20Code-181717?style=flat-square&logo=github)](https://github.com/Hassan141998/AI-Resume-Analyzer)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask)
![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)
![Neon](https://img.shields.io/badge/Neon%20DB-00E599?style=flat-square&logo=postgresql&logoColor=white)
![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel)

**What it does:**
- Accepts **PDF and DOCX** resume uploads and matches them against a job description using **TF-IDF cosine similarity** (keyword 60% + skills 20% + format 20%)
- Detects **150+ skills** across 8 categories, identifies skill gaps, and flags **ATS formatting issues** that block applicant tracking systems
- Generates a **downloadable PDF report** with personalised improvement suggestions and an animated score dashboard with confetti on high scores
- **Admin analytics dashboard** (Chart.js) showing all historical analyses with search, filter, and delete — backed by **Neon PostgreSQL**
- Glassmorphism dark UI with animated particle background, built with HTML5/CSS3/Vanilla JS and deployed on Vercel

**Stack:** Python · Flask · scikit-learn (TF-IDF) · pdfplumber · ReportLab · Chart.js · Neon PostgreSQL · Vercel
